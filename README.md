# Pour Irène

Une déclaration à faire défiler, en HTML, CSS et JavaScript natifs.
Aucune dépendance, aucune installation, aucune donnée collectée.

## Les cinq moments

1. **L'ouverture** — son prénom en grand, écrit à la plume, sur un ciel étoilé
   généré au chargement.
2. **Le compteur** — « À quel point je t'aime ? » : la mesure monte jusqu'à 100 %,
   puis lâche et affiche ∞.
3. **Les raisons** — six cartes à retourner d'un clic.
4. **La lettre** — l'en-tête s'écrit lettre par lettre, les paragraphes montent
   un par un, la signature arrive en dernier.
5. **Le bouton** — « Je t'aime » fait jaillir des cœurs ; le nombre d'appuis est
   gardé sur l'appareil et le message évolue au fil des clics.

## À personnaliser

Les six raisons et le texte de la lettre sont dans `index.html`, les messages du
bouton dans `script.js`. Ils sont écrits volontairement larges — à remplacer par
vos souvenirs à vous.

## Lancer le site

Ouvrir `index.html` dans un navigateur.

## Fichiers

- `index.html` — les cinq scènes et tous les textes
- `style.css` — le thème nuit, les animations et le responsive
- `script.js` — le ciel, les apparitions au défilement, le compteur, les cartes
  et le bouton final
